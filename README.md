# 🚀 Python Web Scraping & Automation Suite

¡Bienvenido a mi repositorio de automatización y extracción de datos! Este proyecto contiene herramientas desarrolladas en Python para la extracción eficiente de datos web, limpieza y exportación estructurada a formatos como Excel y CSV.

---

## 🛠️ Tecnologías y Librerías Utilizadas

* **Lenguaje Principal:** Python 3.x
* **Extracción de Datos:** `requests`, `BeautifulSoup4`
* **Procesamiento y Exportación:** `pandas`, `openpyxl`

---

## 📌 Proyectos y Scripts Incluidos

### 1. `plantilla_scraper_pro.py` (Universal Web Scraper to Excel)
* **Descripción:** Script configurable diseñado para extraer títulos, enlaces y metadatos de sitios web o listados y guardarlos automáticamente en un libro de Excel.
* **Características:**
  * Inyección de `Headers` (User-Agent) para evitar bloqueos por cabeceras básicas.
  * Manejo de excepciones y respuestas HTTP (`status_code`).
  * Estructuración automática de datos mediante DataFrames con Pandas.

### 2. `scraper.py`
* **Descripción:** Script funcional para tareas específicas de extracción y parsing HTML.
